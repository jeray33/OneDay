# 当天页性能回归

## 自动检查

在项目根目录执行：

```sh
swift test
xcodebuild -project OneDay.xcodeproj -scheme OneDay \
  -destination 'generic/platform=iOS Simulator' -configuration Debug build
```

策略测试覆盖视口加载滞回、内容/屏幕坐标换算、封面均匀采样与无结果/部分结果兜底、历史照片稳定选择、闰日、跨年及夏令时。

## 真机检查（尚未代替人工执行）

使用照片超过 300 张的一天，并开启 iCloud 优化存储。分别测试本地图、仅云端图、视频/实况照片，以及共享相簿：

- 快速滚动、反复滚动和快速拖动刻度条，不应反复变成空图。
- 捏合列数、切换瀑布流/对齐、开关懒网格和 caption，当前锚点不跳。
- 点击已加载照片应立即起飞；验证关闭落点及飞回屏外照片。
- 预览连续翻页、下拉关闭、上滑暂存删除、撤销、批量删除、隐藏、相簿标签。
- 旋转后立即翻页/关闭，再进入时照片方向和清晰度正确。
- 视频播放/暂停、进度拖动、实况播放、翻背面及分享。
- 从隧道进入，切换前后日期，封面选定后不自动换图。
- 仅云端照片也应约 1.2 秒内完成封面选图兜底。最终图片清晰显示仍取决于 iCloud 下载。
- 往年今日先显示年份/照片/数量，再补地名。图库后台同步、新增照片时已显示内容不清空，仍有效的所选照片不替换。
- 删除历史所选照片时只补缺失照片；整天无照片时移除该条目。
- 快速切换日期、回到之前日期、退出当天页，旧地名任务不得覆盖当前内容。

## 性能记录

Debug scheme 的启动参数加入 `-OneDayPerformanceTrace`，在 Console 按 subsystem `OneDay` 过滤：

- `PreviewPerformance`：缓存命中和点击处理到准备起飞的耗时，不包含最终屏幕呈现。
- `CoverPerformance`：有限采样评分耗时与已完成的本地评分数。
- `CaptureClock`：历史照片列表就绪及地名补齐耗时。
- `ScrollPerformance`：每段滚动的采样数、慢间隔数与最大间隔。仅开启上述参数时采样。

同一设备、同一天、相同滚动路径下，分别记录冷缓存和热缓存各三次。用 Instruments 的 Animation Hitches、Time Profiler 和 Allocations 验证掉帧、主线程工作与内存；显示刷新回调只是辅助指标，不能代替渲染分析。当前自动测试和构建不代表真机帧率已验证。
