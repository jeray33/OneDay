# 当天页性能回归

## 自动检查

在项目根目录执行：

```sh
swift test
xcodebuild -project OneDay.xcodeproj -scheme OneDay \
  -destination 'generic/platform=iOS Simulator' -configuration Debug build
```

策略测试覆盖视口加载滞回、内容/屏幕坐标换算、封面均匀采样与无结果/部分结果兜底、历史照片稳定选择、闰日、跨年及夏令时。
地名策略还覆盖省略号加载占位、国内外相邻同名地点合并、未知地点不合并、GeoNames 离线兜底（含打包数据的巴黎/尼斯查询与合并）、真实有限重试与取消、双服务错误分类，以及旧版无结果缓存失效。
瀑布流策略覆盖 480 项的可见索引、1～6 列查询与全量扫描一致、缓冲区滞回、预览目标保留、屏外定位及编辑后锚点恢复。布局预计算包含边框、两行 caption 和地点卡片，滚动时只创建缓冲区内格子；不改变图片请求尺寸与原有视觉效果。

## 真机检查（尚未代替人工执行）

使用照片超过 300 张的一天，并开启 iCloud 优化存储。分别测试本地图、仅云端图、视频/实况照片，以及共享相簿：

- 快速滚动、反复滚动和快速拖动刻度条，不应反复变成空图。
- 捏合列数、切换瀑布流/对齐、开关懒网格和 caption，当前锚点不跳。
- 重点复测 **2025-10-12 的 480 张照片/视频**：瀑布流快速往返滚动、刻度条跳到中后段、跨多段捏合；地点卡片分别测试连续/分段、方形/竖版。对齐网格的懒加载开关行为应保持不变。
- 开启 caption，检查中英文、换行、emoji 和两行截断。预览跳到尚未显示的照片再关闭，应定位到该照片；旋转或删除导致前方分段高度变化时也应正确恢复。
- 点击已加载照片应立即起飞；验证关闭落点及飞回屏外照片。
- 预览连续翻页、下拉关闭、上滑暂存删除、撤销、批量删除、隐藏、相簿标签。
- 旋转后立即翻页/关闭，再进入时照片方向和清晰度正确。
- 视频播放/暂停、进度拖动、实况播放、翻背面及分享。
- 从隧道进入，切换前后日期，封面选定后不自动换图。
- 仅云端照片也应约 1.2 秒内完成封面选图兜底。最终图片清晰显示仍取决于 iCloud 下载。
- 往年今日先显示年份/照片/数量，再补地名。图库后台同步、新增照片时已显示内容不清空，仍有效的所选照片不替换。
- 删除历史所选照片时只补缺失照片；整天无照片时移除该条目。
- 快速切换日期、回到之前日期、退出当天页，旧地名任务不得覆盖当前内容。
- 页面取色等待 iCloud 时，轨迹地名仍应独立加载。后面的地点命中缓存时，不得被前面的未缓存地点阻塞。
- 地名查到一个，轨迹和对应分段立即同步更新，相邻且同名的已解析地点合并，不被其他仍在加载的地点阻塞；原始照片地理分段规则不变。
- 国内外地点加载时均仅显示“……”，不插入临时城市估计和“大致位置”括号。卡片上的省略号轻微明暗循环，尺寸固定；滚出屏幕、切到后台、启用“减弱动态效果”时停止动画。
- 在线查询失败/超时、确认无结果、重试预算耗尽或仅返回国家时，使用现有 GeoNames 离线城市库作为最终城市/城镇名；已缓存无结果也应得到兜底。命中后直接显示地名、停止动画并合并相邻同名地点，不等待额外重试；在线详细地名优先，离线名不写入精确缓存。覆盖范围以现有城市库和 50 km 搜索上限为准，不代表精确景点/街道。
- GeoNames 也无覆盖时，临时网络错误最多重试 4 次，退避 2 / 8 / 30 秒，沿用单请求 1.4 秒限流和共享请求去重。每个在线服务请求设 10 秒超时并取消底层请求；整页时间仍取决于排队长度。最终失败/确认无结果后显示“地点 N”，停止加载动画。
- 国外地点的主服务返回无结果、MapKit 却网络失败时，不能缓存成“一周无结果”。旧版无结果缓存重新查询，但保留旧版成功地名缓存。网络恢复后的重试可更新地名；快速切换分类/日期时，旧查询不能覆盖新内容。

## 性能记录

Debug scheme 的启动参数加入 `-OneDayPerformanceTrace`，在 Console 按 subsystem `OneDay` 过滤：

- `PreviewPerformance`：缓存命中和点击处理到准备起飞的耗时，不包含最终屏幕呈现。
- `CoverPerformance`：有限采样评分耗时与已完成的本地评分数。
- `CaptureClock`：历史照片列表就绪及地名补齐耗时。
- `ScrollPerformance`：每段滚动的采样数、慢间隔数与最大间隔。仅开启上述参数时采样。
- `WaterfallPerformance`：布局预计算耗时和实际创建的格子数/总数。稳定滚动不应重复全量规划；普通 480 项的 3 列页面应仅保留视口及缓冲区附近的数十个格子，另加当前预览目标。多分段时需合计各网格，不能把策略测试中的数量当作真机测量。

同一设备、同一天、相同滚动路径下，分别记录冷缓存和热缓存各三次。用 Instruments 的 Animation Hitches、Time Profiler 和 Allocations 验证掉帧、主线程工作与内存；显示刷新回调只是辅助指标，不能代替渲染分析。当前自动测试和构建不代表真机帧率已验证。
